# 86XIng Homebrew Tap

Homebrew casks for [PasteAll](https://github.com/86XIng/paste-all), a macOS menu bar app that pastes clipboard content into Finder as files.

```sh
brew install --cask 86xing/tap/paste-all
```

Upgrade with `brew upgrade --cask paste-all`. Casks here are updated automatically by the PasteAll release workflow; please open issues in the [PasteAll repository](https://github.com/86XIng/paste-all/issues).
